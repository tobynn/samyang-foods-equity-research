# 삼양식품 가치평가 요약

## 1. 평가 기준

평가 기준일은 2026년 6월 30일이며, 2026H1 실적을 기준점으로 2026E–2030E Base 전망을 사용한다. 모든 결과는 독립 가정에 따른 포트폴리오 계산값이다.

## 2. DCF

FCFF는 `NOPAT + D&A - CAPEX - ΔNWC`로 계산했다. Base FCFF는 2026E 2,946억원에서 2030E 8,279억원으로 증가한다.

- WACC: 8.5%
- 영구성장률: 2.5%
- 할인 방식: mid-year convention
- 2026H1 순현금: 763억원
- 발행주식수: 753.2만주(임시)
- 산출 주당가치: **1,632,117원**

## 3. PER

2027E Base EPS 92,839원을 사용했다. 2027E Orion·Nongshim 중앙값 9.815배에 관찰된 평균 프리미엄 약 50%를 적용한 14.72배를 사용하면 주당가치는 **1,366,590원**이다.

| 구분 | 적용 PER | 주당가치 |
|---|---:|---:|
| Bear | 13.25배 | 1,230,117원 |
| Base | 14.72배 | 1,366,590원 |
| Bull | 16.19배 | 1,503,063원 |

자세한 비교기업 선정과 프리미엄 근거는 `research/PER_PREMIUM_FRAMEWORK.md`에 기록했다. 현재 시장 프리미엄을 그대로 목표 배수로 쓰면 순환논리가 생길 수 있으므로 PER은 상대가치 점검값으로 사용한다.

## 4. RIM

RIM은 기초 장부가치에 미래 초과이익의 현재가치를 더한다. 현재 저장소에는 2026H1 지배주주 자기자본 대사값이 없으므로 기초 자기자본 1.2조원을 임시로 넣었다.

- 자기자본비용: 9.0%
- 배당성향: 15.0%
- 장기 ROE: 14.0%
- 영구성장률: 2.5%
- 산출 주당가치: **784,293원**

이 값은 기초 자기자본 확정 전의 점검값이다. DCF·PER보다 낮은 이유는 초기 장부가치와 장기 ROE에 민감하기 때문이다. 공시 대사 후 결과가 크게 바뀔 수 있다.

## 5. 결과 해석

DCF는 163만원, PER은 137만원을 제시한다. RIM은 임시 장부가치 탓에 78만원으로 낮다. 세 값을 기계적으로 평균하지 않는다. 현재 단계의 중심 결과는 DCF이며, PER은 시장 배수 점검용, RIM은 장부가치·ROE 가정 점검용으로 쓴다.

## 6. 최종 공개 전 확인사항

1. DART 반기보고서에서 지배주주 자기자본·발행주식수 확정
2. 비교기업 컨센서스 출처와 기준일 갱신
3. WACC의 무위험수익률·베타·시장위험프리미엄·세후차입비용 계산표 추가
4. 리스부채 포함 여부와 순현금 정의 통일
5. 기존 DCF·RIM Excel 원본의 입력값을 이 문서와 일치시킴
