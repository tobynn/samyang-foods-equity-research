# 삼양식품 가치평가 요약

## 1. 평가 기준

평가 기준일은 2026년 6월 30일이며, 2026H1 실적을 기준점으로 2026E–2030E Base 전망을 사용한다. 모든 결과는 독립 가정에 따른 포트폴리오 계산값이다.

## 2. DCF

FCFF는 `NOPAT + D&A - CAPEX - ΔNWC`로 계산했다. Base FCFF는 2026E 2,946억원에서 2030E 8,279억원으로 증가한다.

- WACC: 8.5%
- 영구성장률: 2.5%
- 할인 방식: mid-year convention
- 2026H1 순현금: 763억원
- 발행주식수: 7,533,015주
- 산출 주당가치: **1,631,897원**

## 3. PER

2027E Base EPS 92,839원을 사용했다. 2027E Orion·Nongshim 중앙값 9.815배에 관찰된 평균 프리미엄 약 50%를 적용한 14.72배를 사용하면 주당가치는 **1,366,590원**이다.

| 구분 | 적용 PER | 주당가치 |
|---|---:|---:|
| Bear | 13.25배 | 1,230,117원 |
| Base | 14.72배 | 1,366,590원 |
| Bull | 16.19배 | 1,503,063원 |

자세한 비교기업 선정과 프리미엄 근거는 `research/PER_PREMIUM_FRAMEWORK.md`에 기록했다. 현재 시장 프리미엄을 그대로 목표 배수로 쓰면 순환논리가 생길 수 있으므로 PER은 상대가치 점검값으로 사용한다.

## 4. RIM

RIM은 기초 장부가치에 미래 초과이익의 현재가치를 더한다. 기초 자기자본은 2026H1 DART 공시와 대조한 연결 자본총계 1.5483조원을 사용했다.

- 자기자본비용: 9.0%
- 배당성향: 15.0%
- 장기 ROE: 14.0%
- 영구성장률: 2.5%
- 기초 자기자본: 1.5483조원
- 산출 주당가치: **837,658원**

RIM이 DCF·PER보다 낮은 이유는 현재 높은 수익성이 장기적으로 14% ROE에 수렴한다고 가정했기 때문이다. 현재 수익성의 지속 기간과 장기 ROE가 핵심 민감 변수다.

## 5. 결과 해석

DCF는 163만원, PER은 137만원, RIM은 84만원을 제시한다. 세 값을 기계적으로 평균하지 않는다. DCF는 성장 투자와 현금흐름을, PER은 시장의 성장 프리미엄을, RIM은 장기 ROE의 정상화를 각각 점검하는 독립 축으로 사용한다.
