# 삼양식품 가치평가 요약

## 1. 평가 기준

모델 최신 실제 실적기간은 2026H1이며, DCF/RIM의 평가일 및 기준주가는 2026-09-18로 맞췄다. 재무제표 기준기간 말은 별도로 2026-06-30이다. Peer 가격·추정치가 같은 시점인지 확인되지 않은 항목은 과거 스냅샷으로 취급한다. DCF/RIM 내재가치 숫자는 기존 가정의 계산 결과이며, PER은 별도 시장 스냅샷 민감도다. 다음 정식 릴리스 전에는 기준일·reference price·peer 추정기간을 통일한다.

## 2. DCF

FCFF는 `NOPAT + D&A - CAPEX - ΔNWC`로 계산했다. Base FCFF는 2026E 2,946억원에서 2030E 8,279억원으로 증가한다.

- WACC: 8.5%
- 영구성장률: 2.5%
- 할인 방식: mid-year convention
- 2026H1 순현금: 763억원
- 발행주식수: 7,533,015주
- 산출 주당가치: **1,631,897원**

## 3. PER

2027E Base EPS 92,839원을 사용했다. 기존 2026-09-18 스냅샷의 Orion·Nongshim 중앙값 9.815배에 분석자 시나리오 +50%를 적용한 14.72배 결과는 **1,366,590원**이다. 이 +50%는 관찰 프리미엄을 재사용한 민감도 입력이며 검증된 정상 프리미엄이 아니다. Peer 표본·추정치 기준일의 작은 크기와 정합성 때문에 상대가치 참고로만 해석한다.

| 구분 | 적용 PER | 주당가치 |
|---|---:|---:|
| Bear | 13.25배 | 1,230,117원 |
| Base | 14.72배 | 1,366,590원 |
| Bull | 16.19배 | 1,503,063원 |

자세한 비교기업 선정, 정량 포함 게이트, 프리미엄 증거 조건은 `research/PEER_SELECTION_SCORECARD.md` 및 `research/PER_PREMIUM_FRAMEWORK.md`에 기록했다. 지역별 성장-생산-현금화 연결은 `research/COMPANY_SPECIFIC_FRAMEWORK.md`, 날짜·갱신 순서는 `research/VALUATION_VINTAGE_POLICY.md`를 따른다. 현재 시장 프리미엄을 그대로 목표 배수로 쓰면 순환논리가 생길 수 있으므로 PER은 상대가치 점검값으로 사용한다.

## 4. RIM

RIM은 기초 장부가치에 미래 초과이익의 현재가치를 더한다. 기초 장부가치는 2026H1 연결 자본총계 1.5483조원의 잠정 proxy다. 현재 저장소만으로 지배주주 귀속 자본과 비지배지분을 완전히 대사하지 못했으므로 RIM per-share 결과는 provisional로 표시한다.

- 자기자본비용: 9.0%
- 배당성향: 15.0%
- 장기 ROE: 14.0%
- 영구성장률: 2.5%
- 기초 자기자본: 1.5483조원
- 산출 주당가치: **837,658원**

RIM이 DCF·PER보다 낮은 이유는 현재 높은 수익성이 장기적으로 14% ROE에 수렴한다고 가정했기 때문이다. 현재 수익성의 지속 기간과 장기 ROE가 핵심 민감 변수다.

## 5. 결과 해석

DCF는 163만원, PER은 137만원, RIM은 84만원을 제시한다. 세 값을 기계적으로 평균하지 않는다. DCF는 성장 투자와 현금흐름을, PER은 시장의 성장 프리미엄을, RIM은 장기 ROE의 정상화를 각각 점검하는 독립 축으로 사용한다.

## 6. 검토 및 남은 증거 게이트

DCF 가치 중 terminal value 비중은 79.7%로 높다. 이 값은 WACC·장기성장률·성숙기 ROIC에 민감하므로 DCF를 단독 목표가로 쓰지 않는다. 다음 갱신에서는 지역·제품별 sell-through와 volume / price-mix / FX / capacity / marketing·logistics 비용의 원인분해를 보강한다. RIM 자기자본 귀속과 PER peer의 날짜·추정기간 정합성을 완료하기 전까지 세 방법의 단순 평균은 사용하지 않는다. 상세 리뷰는 [`research/ANALYSIS_REVIEW.md`](../research/ANALYSIS_REVIEW.md)를 참고한다.
