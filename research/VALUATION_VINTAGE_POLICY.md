# Valuation Vintage Policy — Samyang Foods

## 1. 목적과 현재 데이터 컷

가치평가 숫자는 실적기간, 전망치 스냅샷, 주가, 환율, 주식수의 기준일이 함께 맞아야 해석할 수 있다. 이 저장소의 현재 포트폴리오 계산은 **2026H1 연결 실적을 최신 역사적 기준점**으로 사용한다. PER 비교표는 기존 데이터에 적힌 **2026-09-18 종가 기준**이며, DCF/RIM 결과는 현금흐름·자기자본의 내재가치 계산이므로 시장가격 입력과 구분한다.

> 공개 전 확인할 사항: 보고서 표지의 평가일, 모델의 Reference Price, peer 가격·컨센서스 수집일, 최신 공시 컷오프가 모두 일치하는지 점검한다. 서로 다른 날짜를 합친 결과는 단일 시점의 목표가처럼 표현하지 않는다.

| 항목 | 현재 입력 기준 | 분류 | 갱신 규칙 |
|---|---|---|---|
| 역사적 재무 기준 | 2026H1 연결 실적 | 공시 실적 | 다음 분·반기·사업보고서 확정 수치로 대체 |
| PER peer 관찰치 | 기존 파일 기준 2026-09-18 | 시장·추정 스냅샷 | 종가 및 FY1/FY2 EPS 추정의 동일 날짜 저장 |
| DCF 전망 | 2026E–2030E Base/Bear/Bull | 분석자 전망 | 공장 램프·지역별 수요·가격·원가 가정 변경 이력 기록 |
| RIM 기초 자기자본 | 2026H1 연결 자본총계 1.5483조원 | 공시 실적 | 지배주주 귀속 자본, 비지배지분, 우선주를 재확인 |
| 주식수 | 7,533,015주 | 기준값 | 자사주, 증자, 분할/병합, 전환증권 반영 |
| 환율 | 모델에 직접 쓰인 값 또는 간접 내재값 | 시장 입력/가정 | 매출통화와 원가통화별 평균 환율을 구분 |

## 2. 데이터 상태 라벨

- **Reported**: DART 연결 재무제표, 사업·반기·분기보고서, 회사 IR에서 확인한 확정치.
- **Guidance**: 경영진이 명시한 전망이나 생산/투자 계획. 내부 추정과 섞지 않는다.
- **Consensus**: 수집일, 제공자, 추정기간이 적힌 외부 추정치. 모델의 Base를 자동 대체하지 않는다.
- **Analyst assumption**: 본 프로젝트가 정한 성장률, 마진, 장기 ROE, WACC, terminal growth, multiple.
- **Scenario**: Bear/Base/Bull에서만 달라지는 가정. 확정 사실처럼 표현하지 않는다.

## 3. 시장가격과 비교기업 데이터 동기화

PER 표본에는 종가·시가총액·주식수·EPS 추정기간·통화·회계연도 마감을 한 행에 보관한다. 한국 기업은 회계연도와 결산월이 같아도 FY1/FY2 정의가 제공자마다 다를 수 있으므로, FY 라벨 대신 달력연도 추정인지 회계연도 추정인지 기록한다. trailing PER, NTM PER, CY2027 PER를 한 중앙값에 섞지 않는다. 음수 또는 비정상적으로 작은 EPS는 PER 중앙값에서 제외하고 사유를 남긴다.

## 4. 분기·연간 실적 발표 후 갱신 순서

1. DART 공시와 공식 IR에서 연결/별도, 누적/분기, 단위, 확정/잠정 여부를 대조한다.
2. 지역별 해외매출, 제품·채널 믹스, 가동률, CAPEX, 재고, 매출채권, 현금·차입금 변화를 실제값 시트에 입력한다.
3. 연간 누적액 차감으로 산출한 분기치인지 회사가 제시한 분기치인지 표시한다.
4. 전망 변경을 가격/물량/믹스/환율/원재료/운임/마케팅/고정비/램프업 요인으로 분해한다.
5. DCF, RIM, PER를 재계산하고 이전 버전 대비 가치 변화를 실적 업데이트와 가정 변경으로 나눠 기록한다.
6. PDF와 요약 표의 평가 기준일, 단위, 최신 actual 기간을 동기화한다.
